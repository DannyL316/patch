HOW IT WORKS

Conservative by design

What counts as a buff?

Only direct Summoner's Rift champion changes classified as a genuine buff count toward Strong Champions. Mixed role shifts and compensation changes are stored as adjustments, while nerfs never subtract an earlier buff.

System-wide, item, rune, Arena, ARAM and League Classic changes are visible only through Riot's source page and do not count toward this tracker.

Official Riot wording

The app stores a short paraphrase of Riot's intent plus a direct source link. It deliberately avoids mirroring whole copyrighted patch-note passages.

Updating

The included Node script checks Riot's patch index, keeps the newest five patches, extracts the normal Champions section, and conservatively classifies obvious buffs and nerfs. Ambiguous changes are marked for review and can be fixed in data/overrides.json.
